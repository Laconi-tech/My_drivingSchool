# My_drivingSchool

Pour ce projet je devais créer le site d'une auto école, il fallait créer une interface administrateur afin de gérer les différentes autorisation, pouvoir plannifier des heures de conduite entre élèves et instructeur et en utilisant le frameworks python "Django"

# commande pour lancer le projet
- git clone le projet
- cd [ton dossier]

		- python3 manage.py runserver
commence à gérer ton auto école 😁
